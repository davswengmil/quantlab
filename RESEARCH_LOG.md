Project Question: How reliable is mathematical portfolio optimisation when its inputs are uncertain?

Initial Setup:
- Language: Python 3.12
- Evironment: Linux Mint (Python Virtual Environment)
- Libraries: NumPy, pandas, SciPy, and pytest
- Devlopment Environment: Visual Studio Code

Initial Research Goals:
- Understand how portfolio returns and risk are calculated.
- Implement and compare different portfolio allocation tactics.
- Investigate how estimation errors can affect optimisation results.
- Test strategies using historical data without introducing look-ahead bias.
